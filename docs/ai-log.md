### [2026-10-10] 홈 화면 v1 (워크숍 Step 2 → 첫 결과)
1. **단계와 목표**: 홈 화면 하나. 수용 기준 — 세 상태 동작 / 375px에서 안 잘림 / Tab 키로 모든 버튼 도달 / 대비 4.5:1 이상·이모지·그라데이션 없음 / 연타해도 안 깨짐 / 색은 CSS 변수 한 곳에서 변경
2. **AI 활용 내역**: Claude Code / 아래 프롬프트 / `docs/screenshots/home-v1.jpg`
   ```
   phoU 앱의 '홈' 화면 하나만 만들어줘. (규칙은 AGENTS.md)
   · 사용자: 모임·여행 뒤 친구와 사진을 나누려는 20-30대, 공유 앨범 4개가 있는 기존 유저
   · 화면 요소: 상단 작은 회색 보조 문구 + 큰 굵은 문구 "친구와 사진을 공유해볼까요?", 알림 벨 /
     내 앨범 2열 카드(대표 사진 자리, 이름, 날짜, 멤버 수) / 하단 탭바 3칸: 앨범 / ＋ 새 앨범 / 내 정보

   · 동작: 카드 → 공유된 앨범 보기, ＋ → 앨범 만들기 예정이니 지금은 안내 문구만. 내 정보 → "준비 중인 기능이에요"
   · 디자인: AGENTS.md 미니멀 흑백. Clutter 홈처럼 큰 질문형 문구가 주인공, 카드는 회색 면+얇은 테두리, 탭바는 테두리 있는 알약
   · 하지 말 것: 사진 대신 회색 박스. 실제 사람 이름 금지.
   지금은 이 화면만 만들고 이후 과정 결정할게. 다른 화면은 만들지 마.
   ```
3. **판단**: AI가 프롬프트 밖에서 정한 것 — 보조 문구 내용("이번 주말에 찍은 사진 36장이 그대로 있어요"), 빈 상태의 "새 앨범 만들기" 버튼, 알림 벨도 "준비 중" 안내. (받아들일지 검토 필요)
4. **검증**: WebKit 자동 캡처로 로딩·기본·빈 상태·완료·375px 확인. 스크립트로 Tab 순서(알림 → 카드 4개 → 탭바 3개), 최저 명도대비 4.80:1(카드 날짜 글씨), 16px 미만 본문 없음, 카드 5연타 시 토스트 1개, 가로 넘침 없음, CSS 변수 밖 색 하드코딩 없음 → 수용 기준 6개 모두 통과
5. **윤리 점검**: 앨범 이름은 상황 이름만, 사람 이름 없음. 코드 전체 AI 생성

### [2026-10-10] QR·링크 보내기 화면 v1 (invite)
1. **단계와 목표**: 앨범을 만든 직후 친구를 초대하는 화면. 수용 기준 — create에서 쓴 앨범 이름 표시 / 복사 시 실제 클립보드 + 연타해도 토스트 1개 / 유효기간 바꾸면 날짜 즉시 변경 / 앨범 정보 없으면 오류 상태 / 완료 → 홈 NEW / 375px·키보드·대비
2. **AI 활용 내역**: Claude Code / 프롬프트(아래) / `docs/screenshots/invite-v1.jpg`
   ```
   phoU 앱의 'QR·링크 보내기' 화면 하나만 만들어줘. (규칙은 AGENTS.md)
   · 사용자: 방금 공유 앨범을 만들고 친구들을 초대하려는 사람

     QR(가장 크게) / 공유 링크 + 복사 / 카카오톡·인스타그램·메시지·더보기 / 유효기간 1·7·30일 / 하단 "완료" → 홈

   · 하지 말 것: 외부 QR 라이브러리 금지 (QR은 모양만, 스캔 안 돼도 됨)
   · 공유 버튼: 카카오톡·인스타그램은 실제 로고 모양, 원래 브랜드 색
   ```

3. **판단**: 결정 — QR은 진짜 대신 모양만(라이브러리 금지 + 유지보수). 로고는 처음에 흑백을 추천받았지만 실제 앱처럼 보이도록 브랜드 색으로 결정 → AGENTS.md에 "로고 예외" 규칙 추가(AI가 나중에 흑백으로 되돌리지 않게). 고친 것 — 공유 버튼 글씨가 14px라 본문 16px 규칙 위반 → 16px로 올리고 375px에서 안 넘치는지 확인
4. **검증**: 앱 브라우저에서 create → invite → 완료 → 홈 흐름 실제 테스트. 실제 클릭으로 클립보드에 `https://phou.app/a/...` 들어간 것 확인(스크립트 클릭은 브라우저 보안상 복사가 안 됨 — 사람 클릭 필요). 복사 3연타 → 토스트 1개. 30일 선택 → "2026.11.09까지" 즉시 변경, 저장값도 반영. id 없이 열면 오류 상태. 최저 대비 4.80:1, Tab 순서 복사 → 공유 4개 → 기간 → 완료
5. **윤리 점검**: 카카오톡·인스타그램 로고는 서비스를 알아보게 하려는 프로토타입 용도로만 사용(상표권은 각 회사). 로고 모양은 SVG로 단순화해 직접 그림. 가짜 QR은 실제 주소로 연결되지 않음. 코드 전체 AI 생성
