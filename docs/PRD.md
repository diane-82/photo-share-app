# PRD — phoU 사진 공유 앱 (팀 광명)

> 4주차 PPT(PRD 파트)에서 옮김. 화면 순서와 이후 결정은 FLOW.md 참고.

**타겟 사용자**
- 주 사용자: 모임·여행·행사에서 사진을 찍고 친구에게 보내는 20-30대 (보내는 사람)
- 보조 사용자: 링크로 사진을 받고 자기 사진을 보태는 친구 (앱 설치 없음)
- 언제: 모임 직후, 여행 후 정리할 때, 단체 사진을 나눠야 할 때
- 쓰는 곳: 앱(확장기능), 모바일 웹
- 기기: 아이폰·갤럭시 혼재, 20대는 거의 반반 (한국갤럽 2026년 7월 조사 보도)
- 대표 상황: ① 단톡방에 수십 장이 올라오는데 "내가 나온 사진"을 찾기 어렵다 ② 같은 장면을 여러 장 찍었지만 뭘 보낼지 고르기 귀찮아 아예 안 보낸다 ③ 친구와 기종이 달라 에어드롭이 안 되고, 카톡은 화질이 깎인다

**문제 · 근거 (출처)**
- 좋은 사진의 기준이 종류·목적마다 다르다. 1순위 얼굴·표정 50%, 2순위 "내가 원했던 사진과 비슷한지" 41.7% (설문 12명)
- 좋은 사진을 건지려고 여러 장 찍지만 그 과정을 불편해하고, 찍은 사진은 지우지 않고 쌓아둔다 (인터뷰 9명 + 설문)
- 받는 사람이 "잘 나왔다, 나도 보내줘" 하고 직접 요청한다 (인터뷰 익명B)
- 보내는 쪽은 흔들린 사진만 빼고 거의 다 보내는 방식을 쓴다 (인터뷰 익명A)
- 카톡은 기본 설정에서 사진을 압축 전송하고 일정 기간 뒤 다운로드가 제한된다 (정확한 기간 확인 필요) (데스크리서치)
- 에어드롭·퀵쉐어 상호 호환은 2026년에 일부 기기부터 시작됐다 (데스크리서치)
- 비리얼·로켓 등 기존 공유 앱은 날것 공유와 압박 줄이기에 집중하고 고르는 수고는 거의 다루지 않는다 (데스크리서치)

**차별점**
- 경쟁: iCloud 공유 사진 보관함(카메라에서 바로 공유, 최대 6명, 애플 기기 중심) / 구글 포토(얼굴 그룹 기준 자동 추가, QR 공유)
- 우리 차별점 = **추천 + 받는 사람의 저장 선택 줄이기** (두 서비스의 공식 설명에서 베스트컷 추천은 확인하지 못함)

**목표 지표**
| 지표 | 제안 기준 | 측정 방법 |
|---|---|---|
| 저장까지 걸린 시간 | 기존 방식(카톡 앨범 스크롤)의 절반 이하 | 같은 사진 세트로 두 방식 비교, Maze 시간 측정 |
| 추천 수락률 | 추천 컷을 그대로 저장한 비율 70% 이상 | 테스트 로그 |
| 교체율 | 추천을 다른 것으로 바꾼 비율 30% 이하 | 테스트 로그 |
| 공유 포기 감소 | "원래 안 보냈을 사진 묶음을 이번엔 보냈다" 응답 비율 | 테스트 후 질문 |
| 기종 무관 사용 성공률 | 아이폰·갤럭시 모두에서 링크 열기와 저장 성공 | 교차 기기 테스트 5명 이상 |

**유저 플로우 (보내는 사람=앱, 받는 사람=웹)**
- 앱·보내는 사람: ①앨범 폴더 만들기(앱이 제안하거나 직접 이름·기간 설정) → ②사전 공유 옵션 설정(본인 단독으로 나온 사진 제외, 흔들린 사진 제외 등) → ③사진 불러오기(공유한 사진 삭제 여부, 사전 설정 맞춤 사진 공유) → ④공유 설정(링크 만료 시간, 비밀번호 선택) → ⑤링크·QR 보내기(단톡방·DM 등 어디로든)
- 웹·받는 사람(앱 설치·가입 없음): ⑥링크·QR로 입장 → ⑦내 사진 추가(선택, 웹에서 올리면 같은 폴더에 추가) → ⑧**AI 추천 확인 (핵심)**: 묶음마다 베스트 1장과 추천 이유 → ⑨공유 앨범 보기·저장(원본 화질로 저장) → ⑩폴더 다시 보기(같은 링크로 나중에 다시 열기) → ⑩홈화면(여러 앨범 모아보기 이외의 기능들)
- ⑧의 부가 기능: 내 사진 모아보기(얼굴 인식으로 사람별 확인) / 비슷한 사진 1개만 남기고 삭제 / 장소별 사진 모아보기(촬영 위치 기반)

**예외 처리**
| 상황 | 화면·동작 |
|---|---|
| 사진 접근을 거부하거나 일부만 허용 | 시스템 사진 선택 화면으로 직접 고르게 하고 이유를 안내 |
| 이벤트 시간대에 사진이 0장 | 빈 상태: "아직 이 시간대에 찍은 사진이 없어요" + 직접 추가 |
| 비슷한 묶음이 없음 | 베스트컷 배지 없이 전체 목록만 표시 |
| 추천이 마음에 안 듦 | 같은 묶음의 다른 컷을 한 번에 펼쳐 교체 |
| 업로드 실패·네트워크 끊김 | 재시도 대기열, 와이파이 연결 시 이어서 업로드, 진행률 표시 |
| 링크 유출 | 만료 시간 설정, 참여 승인 옵션, 만료 링크는 안내 화면 |
| HEIC 등 웹에서 안 열리는 형식 | 서버에서 JPEG 사본을 만들고 원본은 별도 다운로드 |
| 남이 올린 사진을 삭제 | 올린 사람만 삭제 가능 |
