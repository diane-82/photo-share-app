# 워킹 프로토타입 플로우 (앱 기준)

> 로우파이(4주차 PPT 12~17p) 기준. 앱 = 전체 기능, 웹 = 올리기·내려받기만(이번 범위 밖).
> 상태: 논의 중. (확인 필요) 표시는 아직 확정 아님.

## 화면 순서
| # | 화면 | 출처 | 비고 |
|---|---|---|---|
| 1 | 홈 | Lo-Fi 05 | 시작점이자 모든 흐름이 끝나고 돌아오는 곳 |
| 2 | 앨범 폴더 만들기 | Lo-Fi 01 | |
| 3 | 공유 옵션 설정 | Lo-Fi 02 | |
| 4 | 사진 불러오기 | 새로 만듦 | 로우파이 없음 |
| 5 | 공유 설정 | 새로 만듦 | 로우파이 없음 |
| 6 | QR·링크 보내기 | Lo-Fi 03 | |
| 7 | 친구들이 사진을 올렸어요 | 새로 만듦 | 시간 경과 연출용 알림 |
| 8 | AI 추천 확인 | Lo-Fi 04 (1번 스케치) | 핵심 |
| 8-1 | AI 필터 | 새로 만듦 | 날씨 변경·노을 시간대·배경 사람 지우기 |
| 8-2 | 비슷한 사진 정리 | 새로 만듦 | 묶음별 대표 1장 자동 선택·수정 |
| 8-3 | 장소별 사진 | 새로 만듦 | 촬영 위치 기반 분류 |
| 9 | 공유된 앨범 보기 | Lo-Fi 06 | "내 사진만 보기" 필터 포함 |

## 확정된 결정
- 홈이 1번. 흐름을 다 마치면 다시 홈으로
- 사진 삭제는 올린 사람만 가능. 받는 사람에겐 삭제 기능 없음
- 8 AI 추천 확인: 위 카드는 옆으로 넘기며 다음 추천을 보는 용도(저장은 별도 버튼). 아래 버튼 = AI 필터 / 비슷한 사진 정리 / 장소별
- "내 사진 모아보기"는 8에서 빼고, 9의 "내 사진만 보기" 필터로 대신
- 5번(공유 설정)·4번(사진 불러오기) 화면 구성은 Claude가 제안
- 비슷한 사진 정리: 앱 안에서는 전부 보이고, 내 폰(로컬 갤러리)으로 내려받을 때 묶음별 대표 1장만 저장되도록 정리
- 8 AI 추천 카드: 카드 오른쪽 아래 ⬇ 저장 버튼, 누르면 "저장됨"으로 바뀜

- 하단 탭바 3칸: [앨범] [＋ 새 앨범(중앙)] [내 정보]. 앨범 = 홈. 내 정보는 "준비 중" 안내만
- 탭바 숨김: 앨범 만들기 ~ QR 보내기 흐름(✕/뒤로가기로 대체). 그 외 화면은 보임

- 디자인: 핑크 강조색 취소, Clutter 앱처럼 미니멀 흑백
- 홈 상단 문구는 행동 유도형 ("친구와 사진을 공유해볼까요?")
- 홈 앨범 카드 → 공유된 앨범 보기(9). AI 추천은 9에서 버튼으로 진입
- 데모는 기존 유저(앨범 4개)로 시작. 빈 상태는 개발 확인용(`?state=empty`)

## 제작 순서
1. 1차 핵심 흐름: 홈 → 앨범 만들기 → QR 보내기 → AI 추천 확인 → 공유된 앨범 보기
2. 2차: 공유 옵션, 사진 불러오기, 공유 설정, 사진 올라옴 알림
3. 3차 차별 기능: AI 필터, 비슷한 사진 정리, 장소별
